# Roadmap

## Phase 1 — Digital flagship ✅ (this release)

- [x] Premium animated marketing website (11 routes)
- [x] Impact dashboards (Foundation, ESG, manufacturing)
- [x] SEO / structured data foundation
- [x] Infrastructure-as-code and CI/CD baseline
- [x] Database schema and platform architecture

## Phase 2 — Commerce & messaging (next)

- [ ] NestJS backend: catalog, orders, customers, certificates APIs
- [ ] E-commerce: cart, checkout, Paystack/Flutterwave/Stripe, subscriptions
- [ ] WhatsApp Business bot (ordering, tracking, support, distributor onboarding)
- [ ] Telegram bot (catalog, orders, notifications, broadcast channels)
- [ ] Customer portal (orders, invoices, loyalty)
- [ ] Headless CMS for reports, press and knowledge center

## Phase 3 — Ecosystem

- [ ] Distributor, supplier and vendor portals
- [ ] Admin dashboard: orders, inventory, production, CSR tracking
- [ ] CRM: segmentation, loyalty, automated email/SMS/WhatsApp campaigns
- [ ] ERP integration (inventory, invoicing, production planning)
- [ ] AI chatbot with retrieval over the knowledge base; voice assistant
- [ ] Certificate verification API with QR codes

## Phase 4 — Scale

- [ ] Native mobile apps (iOS/Android) per `mobile/` specification
- [ ] Multi-language (EN, FR, AR, HA, YO, IG, SW) and multi-currency
- [ ] Real-time IoT/SCADA production feeds into the digital factory pages
- [ ] Multi-region deployment for 10M+ users (see docs/SCALABILITY.md)
- [ ] Investor portal with live ESG KPIs
